常见问题

“DeepSeek 登录”是什么形式？

DeepSeek API 没有账号 OAuth。所谓登录 = 在 platform.deepseek.com 登录你的 DeepSeek 账号并创建 API Key，粘贴回向导即可。Key 只存本机 ~/.dsh/.credentials.yaml（0600）。

DMG 被 Gatekeeper 拦怎么办？

本安装器未做 Apple 公证。macOS 15：系统设置 → 隐私与安全性 → 仍要打开；或 xattr -d com.apple.quarantine /Applications/"DeepSeek Harness Desktop Installer.app"。介意的话直接用 curl 命令，完全不触发 Gatekeeper。

Paseo 里为什么没有对话上下文？

每个 prompt 回合是一次独立的 dsh --profile headless 运行（dsh headless 无 resume），回合间不保留上下文。

dsh 的遥测怎么关？

export DSH_TELEMETRY_DISABLED=1（写入 shell rc 持久化）。

怎么卸载？

bash install.sh --uninstall：移除 ACP 桥、provider 注册与路由 patch；dsh / Paseo 本体与凭据不动。
